# 审查流程重构验证记录

日期：2026-10-28（Asia/Shanghai）。范围：编码助手技能中的审查职责、自动检查及修复复核；保留原有核心 TDD、架构与复用约束。本轮没有 Git 仓库，以文件摘要和原始输出记录版本。

## 阅读依据与实现选择

已阅读全文 [How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)（2026-10-15）。本轮采用其检查前移、新上下文审查、确认发现、控制复核轮次及用缺陷与干净案例评估的思路。文章描述的组织审批和发布规则不作为本技能的通用要求。

| 本轮实现 | 位置与边界 |
|---|---|
| 确定性检查 → 独立找缺陷 → 核实候选 → 修复复验 → 主 agent 整合 | [代码审查](../references/workflows/代码审查.md)作为统一方法；角色说明引用方法，避免重复门槛 |
| 区分已确认缺陷、待确认、误报、有意行为和原有问题 | 发现需有触发、后果和证据；不以多个 agent 的赞同代替事实 |
| 首次看整体差异，后续看修复及影响；默认三轮后重新评估 | 不因达到轮次就跳过问题，也不无限重复风格建议 |
| 复用现有检查，支持本地事件／CI 调用 | [自动检查](../references/workflows/自动检查.md)和[标准库执行器](../scripts/run_review_checks.py)；不要求安装新审查框架 |
| 当前结果关联输入及配置 | 记录前后摘要、命令和日志；交付时可核实旧结果是否仍有效 |
| 重复问题转为回归或适当规则 | 增加 C-01～C-07 验证条件；保留正确行为作为误报对照 |

人审和安全审查按真实项目要求处理。合并队列、发布和恢复仅在实际任务包含这些步骤时适用；此技能包没有远端仓库或已安装的自动触发入口。

## 维护者场景演练

方式：维护者运行[可复现演练](验证证据/审查重构/场景演练.py)，复制原始订单夹具到临时目录，准备经公开服务调用的 API 和六项接口测试。该准备仅为本轮执行器集成夹具，不声称又完成了一次独立的接口开发任务。原始夹具没有被实现或改写。

| 操作与观察 | 实际结果 |
|---|---|
| 干净实现运行示例配置，并核实旧证据 | 13 项通过；核实返回 0 |
| 将“已取消直接返回”移到所有权判断之前 | 旧代码证据核实返回 3；现有 13 项仍全绿，说明原测试存在覆盖缺口 |
| 根据原始需求补充“非所有者访问已取消订单应拒绝”及合法重复请求对照 | 15 项中 1 项因未抛 PermissionError 失败；合法所有者重复请求仍通过 |
| 恢复正确权限顺序，并复核修复 | 修复前证据失效；15 项全部通过，当前结果核实返回 0 |
| 仅改变检查配置的超时时间，再恢复相同配置 | 核实返回 3，明确 config_changed；恢复完全相同输入后返回 0 |

完整命令、状态、原始日志、每轮报告、注入差异与最终夹具保存在[最终演练工件](验证证据/审查重构/场景完整工件.tar.gz)；紧凑的[操作记录](验证证据/审查重构/场景操作记录.json)保留实际退出码。全部执行器修复后已用最终格式重跑全部演练；[初版工件](验证证据/审查重构/初版场景完整工件.tar.gz)保留其历史范围。历史报告中的临时绝对路径保留当时事实，搬迁工件不代表原地的证据仍可核实；重新演练须指定新的输出目录。

此演练覆盖 C-01／C-03／C-04 的工具与运行证据，以及 C-02／C-07 的有缺陷／干净对照构造；它没有测量独立模型的召回率或误报率。C-05 的归属判断和 C-06 的真实事件／CI 触发仍需在相应宿主或项目中实测。

## 独立复核

首次独立子 agent 调用因使用额度限制未执行。恢复窗口后查询确认普通使用已恢复，已重新提交新上下文只读复核。验证者未读取维护者本轮结果，独立复现了以下两项实质问题：

| 标识 | 原问题、后果与修复 | 状态 |
|---|---|---|
| RC-1（P2） | 只比较内容，执行文件 755→644 后旧结果仍通过，但实际重跑被拒绝。快照现记录文件权限 | 已独立复核解决 |
| RC-2（P2） | 未记录空目录且缺失值与不存在键混同，删除声明输入目录后旧结果仍通过。现记录目录存在性／权限和明确缺失状态 | 已独立复核解决 |
| RC-3（P2） | 文件链接改指相同源码但关联数据不同，旧结果仍通过而实际重跑失败。现保留链接路径和目标身份 | 已独立复核解决 |

修复将证据格式升为版本 2；初版结果不能被新版核实为通过，须重新执行。验证者初查还实际运行了 20 项原测试、示例配置及 9 个额外独立检查，并检查相关本地链接与工作流；元数据修复后实际运行了 23 项现有测试。最后一轮只复核链接身份修复和相邻反例，不扩大为全仓审计。

最终独立复核：剩余已确认问题 0，24 项现有测试、21 个补充断言全部通过。补充断言覆盖递归／显式输入的链接改指、未变链接、越界链接、目录链接与真实目录、前两项回归、多层证据目录排除及其他文件追踪。三项发现均经独立复验关闭；报告中的脚本摘要与最终技能快照一致。

[独立报告](验证证据/审查重构/独立复核报告.txt)保留初查及各轮处置，[完整工件](验证证据/审查重构/独立复核完整工件.tar.gz)包含原始命令、输出、检查脚本及复现材料。独立执行与维护者演练分别计数，重复执行的同一测试不相加为新的用例数量。

## 限制

- 自动检查只覆盖声明的输入、当前配置和实际命令；工具、依赖环境或外部服务变化需另行判断。执行器不是权限隔离或证据防篡改机制。
- 未实际安装宿主事件、CI、分支保护、合并或发布；交付的是可运行入口和接入方法，不声称自动触发已生效。
- 本轮保留既有验证记录、历史证据和原始夹具；旧版独立验证不计入本轮通过数量。
